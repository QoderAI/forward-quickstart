# Forward Demo：按轮展示会话执行过程

## 目标与范围

借鉴 WorkBuddy 的交互：每次提问下方最多一个「执行过程」，把过程、正文和交付产物分开。用户不必理解事件协议就能知道 Agent 在做什么、是否需要自己操作、最后交付了什么。只改文本会话；保留语音、附件、模板、批量和原有多 Agent 协作，不换 SDK 或传输层。不提供推测费用、通用待办协议或完整内部思维链。

## 展示规则

1. 用户消息 → 执行过程 → 回答 → 产物/错误。进行中默认展开过程，结束后默认收起；手动开关优先，审批或问题不因折叠或显示设置而消失。短答无有效过程时不留空壳。过程卡显示状态、最近步骤和可确定的已用时。
2. 工具调用与结果按原始引用合为一行：运行中、待确认、已完成、失败、已拒绝、结果未记录。并行同名工具不能互相匹配。仅提取有明确语义的短字段（搜索词、主机名、文件名），未知工具仅展示名称与状态。原始输入/出参和凭据不得作为默认详情。思考内容仅用 Forward 实际返回的文本，折叠且截断；关闭思考/工具不影响答案、产物、错误和人工操作。协作派发和子线程状态继续使用已有组件。
3. 正文立即流式显示；同一轮内有明确后续调用时，之前的正文才归入过程。结束、失败或停止后，当前页面保留末尾正文和已收到的未完成片段。刷新后只回放服务端已保存的正式事件，不补造未落库的增量。按事件 ID 去重，不按文本相似度删回答。
4. `session.usage` 为会话累计快照，不是加量或本轮费用。读取非负有限值，支持顶层字段和旧嵌套字段，保留零，缺失时用 Session 查询补齐；已有用量报表的兼容口径不变。逐模型调用用量不冒充本轮总费用。

## 事件与状态

| 输入 | 投影 |
| --- | --- |
| `POST /sessions/{id}/events` 返回的 `user.message.id` | 本轮边界；稳定关联本地乐观消息。不依赖可选的 `turn_id`，不按日期或上一条回复切轮。409 不自动重发，恢复未送达的草稿。 |
| `event_start` / `event_delta` / 正式事件 | 按目标事件 ID 与 block index 附加文本，正式事件替换草稿。帧可共享 ID，历史不含临时帧。Thinking Delta 由代理添加 Beta 头。 |
| 内置、MCP、自定义工具调用和结果 | 分别按 `tool_use_id`、`mcp_tool_use_id`、`custom_tool_use_id` 关联；同轮可能存在多个调用。工具失败不等于整轮失败。 |
| `session.status_idle` + `requires_action` | 原轮等待。按 `event_ids` 展示交互，显式允许/拒绝发送 `user.tool_confirmation`；自定义问题发送 `user.custom_tool_result`；兼容旧版问题和跳过。等待期间不计入运行时间。 |
| `session.status_idle` + `end_turn` | 本轮结束，不代表任务目标成功。`session.error`、取消、会话终止各有独立文案；子线程 idle 不结束主轮。 |
| 取消返回 `202` / `200` | `202` 只表示接受，继续等事件或 GET 状态确认；`200` 无活动轮，不宣称本次成功取消。等待确认期间禁用重复取消。 |
| 连接异常 | 回读、重连并提示；不把连接异常当作结束、会话删除或业务失败。 |

## 历史与恢复

历史和 SSE 共用事件投影。按 API 顺序与可用服务端时间合并完整事件，保留同 ID 的增量帧，不能用字典序排序 ID。初载按 `order=desc` 获取最新页、反转；向前翻页用 `before_id`，保留滚动位置。如果最新页从一轮中间开始，显示「部分历史」且不并入下一条用户消息。历史过滤用 API 文档的 `type`（逗号分隔）；不能用非契约的 `types`。重连把 `Last-Event-ID` 传回 SSE，历史补齐处理超过一页的断流缺口；游标失效时报错和回读，不自动重复写操作。切换 Session 后，旧请求不得写入新界面。

活动轮在发起、运行、等待、重连或停止中。仅在已知运行段具有时间戳时计算已用时间，等待用户的间隔不计入；历史无法恢复时不显示猜测值。缺少人工交互对应的历史时仍保留已知待办入口，并提供补载历史的路径。

## 验收

- 用同一套事件跑实时和历史，验证一轮一个过程、同名并行工具按 ID 配对、子线程不结轮、工具失败不覆盖回答、补页不串轮、同 ID 正式事件覆盖增量、断流跨多页可恢复。
- 浏览器走「发送 → 看增量 → 待确认 → 主动处理 → 正文与产物 → 刷新回放」，检查设置、手动折叠、历史加载、会话切换、取消和错误；关注焦点和滚动位置。不向真实 API 发测试写请求。
- 单测、类型/构建、lint 和实际 diff 审查。真实环境的账号权限、Beta 和上游错误格式独立验证，不以模拟测试代替。
